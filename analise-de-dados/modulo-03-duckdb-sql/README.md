# Módulo 3 - SQL com DuckDB

## Objetivo

Desenvolver consultas SQL utilizando DuckDB para importar, tratar, analisar e exportar a base de acidentes da Polícia Rodoviária Federal (PRF).

## Tecnologias

- DuckDB
- SQL
- CSV

## Atividades desenvolvidas

- Importação da base de dados
- Criação da tabela principal
- Criação da variável `acidente_fatal`
- Criação da view `vw_acidentes_base`
- Consultas univariadas
- Consultas bivariadas
- Indicadores estatísticos
- Cálculo de Lift
- Exportação de resultados em CSV
- Elaboração do relatório técnico

## Estrutura do módulo

```text
sql/
relatorio/
resultados/
imagens/
```
